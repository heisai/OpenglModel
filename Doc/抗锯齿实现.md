# OpenGL抗锯齿实现的三层次架构(LearnOpeng 中讲解)
## 第一层：硬件级抗锯齿
- 这种是最简单的抗锯齿实现方式，直接利用OpenGL提供的多重采样功能。
```cpp
// 1. 多重采样（MSAA） - 硬件加速
glEnable(GL_MULTISAMPLE);  // 开启硬件MSAA
// 或
glfwWindowHint(GLFW_SAMPLES, 4);  // 窗口级MSAA
```
## 第二层：渲染管线级抗锯齿
- 采用离屏渲染技术，将场景渲染到多重采样的帧缓冲对象（FBO）中，然后再进行后处理抗锯齿。
- 多重采样不能直接在着色器上使用需要使用单个渲染将其解析为普通纹理。（当前代码实现采用这种方式）
```cpp
// 2. 离屏渲染 + 多种技术
// 2.1 MSAA FBO
glTexImage2DMultisample(GL_TEXTURE_2D_MULTISAMPLE, 4, GL_RGBA, width, height, GL_TRUE);

// 2.2 后处理抗锯齿（FXAA、SMAA、TAA等）
// 渲染到普通纹理，然后应用后处理着色器
``` 
## 第三层：着色器级抗锯齿
- 通过自定义着色器实现更高级的抗锯齿技术，如FXAA（快速近似抗锯齿）、SMAA（子像素形态学抗锯齿）等。
```cpp
glsl
// 3. 着色器优化和自定义算法
uniform sampler2DMS msaaTexture;  // 直接采样多重采样纹理
// 或
uniform sampler2D screenTexture;  // 应用FXAA/SMAA算法
```
